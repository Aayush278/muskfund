# CSS Files

This directory contains all CSS stylesheets for the MUSKFUND project.

## Organization

- Global styles and theme variables are defined inline in HTML files for now
- Future: Extract shared CSS into separate files here

## Best Practices

1. Keep CSS files modular and organized by component
2. Use CSS variables for consistent theming
3. Follow BEM (Block Element Modifier) naming convention
4. Minimize inline styles - prefer CSS classes
